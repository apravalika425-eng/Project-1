RETAIL BUSINESS PERFORMANCE & PROFITABILITY ANALYSIS
======================================================
Submission contents:
1. Retail_Performance_Report.pdf - concise report (maximum two pages)
2. retail_analysis.sql - SQLite-compatible queries
3. retail_transactions.csv - sample transactional data for SQL/Tableau
4. retail_analysis.py - Pandas + Seaborn analysis
5. tableau_category_summary.csv, tableau_subcategory_summary.csv, tableau_seasonal_summary.csv
6. Tableau_Dashboard_Build_Guide.txt - dashboard layout and calculated fields

IMPORTANT DATA NOTE:
The dataset is synthetic/generated for this project because no original dataset was supplied.
Replace it with your actual retail dataset before presenting the numerical findings as real business results.
The guide provides the Tableau dashboard specification; a native Tableau workbook must be saved from Tableau Desktop/Public.

7. Retail_Interactive_Dashboard.html - browser-based interactive dashboard with Region, Category and Season filters.
